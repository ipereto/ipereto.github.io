# ipereto.github.io

Personal portfolio of **Iván Felipe Pérez Torres**, backend developer (Java & Spring Boot).

Live site: https://ipereto.github.io

- **Overview:** availability, current upskilling and career goal, plus an at-a-glance view of technologies grouped by depth.
- **Journey:** education, work and own projects in three parallel lanes. Degrees and jobs group what happened inside them, and a filter shows the evidence for each technical and soft skill.
- **Soft skills:** each one linked to the experiences where it was used.
- **Projects:** featured Kafka Lab with an interactive diagram, plus academic and personal projects.

Static site: one `index.html` with plain HTML, CSS and JavaScript, no build step. Available in English and Spanish, with light and dark themes.
