# ipereto.github.io

Personal portfolio of **Iván Felipe Pérez Torres**, backend developer (Java & Spring Boot).

Live site: https://ipereto.github.io

- **Journey:** education, work and own projects in three parallel lanes, with a skill filter that shows the evidence for each skill.
- **Projects:** featured Kafka Lab with an interactive diagram, plus academic and personal projects.
- **Skills:** grouped by depth.

Static site: one `index.html` with plain HTML, CSS and JavaScript, no build step. Available in English and Spanish, with light and dark themes.
